# Regras para agentes neste repositório

## Sempre veja as telas (regra do dono, vale para todos os agentes)

Mudou página, componente, texto ou imagem do site? Só está pronto depois que você **olhou a página
renderizada**. Lint e tipos passando não bastam.

- Suba o site local (`npm run dev`) e tire captura com Playwright; abra a imagem antes de concluir.
- Confira texto cortado ou sobreposto, imagens quebradas, layout no celular (360 px) e no desktop.
- No relatório final, diga o que você viu; se não conseguiu ver a tela, diga isso.
